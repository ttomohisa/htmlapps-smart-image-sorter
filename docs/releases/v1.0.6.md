# Smart Image Sorter v1.0.6

最大500枚の画像を端末内のAIで仕分けし、分類結果を確認して、元の画像をカテゴリ別ZIPで保存するツールです。登録やインストールは不要です。

## 主な変更

- 分類中の操作と中止処理を見直し、古い結果の混入を防止しました。
- 作業データの復元・自動保存・退避・削除を改善しました。別タブで保存内容が変更された場合は、競合を検知して自動保存を停止します。
- CSVの数式として解釈され得る値、ZIP内のファイル名、画像データのメモリ使用量に関わる処理を見直しました。
- モデル読み込み失敗時の再試行と、開発者向け精度テスト中の操作制御を改善しました。
- 日本語・英語の説明と回帰テストを更新しました。

## Downloads

- `htmlapps-smart-image-sorter-v1.0.6.html` — モデルとランタイムを含む単一HTML。ダウンロードしてブラウザで開けます。
- `htmlapps-smart-image-sorter-v1.0.6.zip` — 同じ単一HTMLに加え、説明書・ライセンス・スクリーンショット・ビルド情報を収録。
- `SHA256SUMS.txt` — HTMLとZIPのSHA-256チェックサム。

## 検証と制限

生成されたHTMLについて、CSP、バージョン、回帰テストをGitHub Actionsで検証してから公開します。アプリは画像を外部に送信せず、モデル処理も端末内で行います。ブラウザがHTMLを取得する通信は別です。

Safari・Firefox・スマートフォン実機でのAI推論、750 MB近いZIPの保存はすべての環境で検証したわけではありません。自動保存の別タブ対策は競合の検知であり、完全な排他制御ではありません。

---

Sort up to 500 images with on-device AI, review classifications, and export the original files grouped in a ZIP. No account or installation is required.

### Highlights

- Prevent overlapping classification runs and stale results after cancellation.
- Improve autosave, recovery backups, validation, and deletion; pause autosave on detected cross-tab conflicts.
- Harden CSV fields, ZIP filenames, and memory use during ZIP construction.
- Clean up temporary model resources on failed initialization and keep accuracy-test inputs stable while running.
- Update Japanese/English documentation and regression coverage.

### Downloads and verification

The standalone HTML embeds the model and runtime. The ZIP includes that same HTML, documentation, licenses, screenshots, and build metadata. The checksums file covers both downloads. CI validates the generated HTML before publication.

Actual Safari, Firefox, mobile-device inference, and near-limit ZIP exports remain environment-dependent and have not all been tested on physical devices.
